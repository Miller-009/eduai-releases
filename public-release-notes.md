# EduAI Desktop v1.1.0

## Highlights

- Improved desktop startup experience and slow-start feedback
- API retry and failure recovery
- Single-instance handling and window recovery
- Improved desktop lifecycle cleanup
- More automated release validation

## Upgrade

Supports in-place upgrade from v1.0.0.

## Known limitations

- The Windows binary is currently unsigned; SmartScreen may appear on some systems.
- Physical multi-monitor validation remains limited.
- Tray icon discoverability can be improved.
