# EduAI 教务助手

EduAI 是一个帮助学生查看和同步教务信息的 Windows 桌面应用。

## 当前版本

**v1.1.0** · Windows 10 / Windows 11

前往 [v1.1.0 正式下载页](https://miller-009.github.io/eduai-releases/) 下载 Windows 安装包。

也可以直接查看 [v1.1.0 Release](https://github.com/Miller-009/eduai-releases/releases/tag/v1.1.0)。

## 安装与使用

1. 下载 Windows 安装包。
2. 双击安装并打开 EduAI。
3. 创建或登录 EduAI 平台账号。
4. 按页面提示绑定学校教务账号。
5. 如出现验证码，请由本人输入。
6. 完成同步后查看成绩和课表。

当前安装包尚未代码签名，部分 Windows 设备可能显示 SmartScreen 提示。请确认下载来源为本仓库后，再按 Windows 提示继续；不要关闭 Defender。

Microsoft Edge 可能显示“通常不会下载”的下载信誉提示。请先确认页面、版本和文件名正确，再按 Edge 下载面板的“更多”→“保留”继续；如果 Windows 安全中心显示具体的恶意软件或 PUA 名称，请停止安装并联系维护者，不要强行绕过安全提示。

## 隐私

请不要通过反馈发送学校密码、平台密码、验证码、Cookie、JWT、Session、身份证号、完整学号或真实成绩明细。详见 [隐私说明](docs/privacy.md)。

## 反馈

如果遇到问题，请使用 [反馈模板](docs/feedback.md) 脱敏填写后，通过你与维护者已有的安全渠道发送。此仓库不会收集表单内容、账号或教务数据。
