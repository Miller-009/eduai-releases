EduAI 教务助手

让教务信息查看和同步更简单。

适用于 Windows 10 / 11 的桌面应用。下载正式版，登录平台账号并绑定学校教务账号后即可开始使用。

下载 Windows 版 查看使用步骤 提交使用反馈

当前版本：v1.1.0 · 安装包：EduAI.Setup.1.1.0.exe

开始使用

  1. 下载并安装。
  2. 打开 EduAI。
  3. 创建或登录平台账号。
  4. 绑定学校教务账号。
  5. 完成同步，查看成绩和课表。

Windows 安全提示

当前安装包尚未代码签名，部分电脑可能显示“Windows 已保护你的电脑”。

确认页面和文件来自 EduAI 正式发布后，可按提示选择“更多信息”→“仍要运行”。不要关闭 Defender。

Microsoft Edge 下载提示

由于安装包尚未代码签名且是新发布文件，Edge 可能提示“通常不会下载”或要求确认信任。这是下载信誉提示，不等同于恶意软件检测。

请先确认当前页面是 miller-009.github.io/eduai-releases、版本为 v1.1.0，文件名为 EduAI.Setup.1.1.0.exe。确认来源无误后，可在 Edge 下载面板选择“更多”→“保留”。不要关闭 Defender 或 SmartScreen。

如果 Windows 安全中心显示具体的恶意软件或 PUA 名称，请停止安装并联系维护者，不要强行绕过。

需要帮助？

打开反馈模板，只填写脱敏信息，再通过你与维护者已有的安全渠道发送。

查看隐私说明。页面不会收集账号或教务数据。

隐私提醒

请不要发送学校密码、平台密码、验证码、Cookie、JWT、Session、身份证号、完整学号或真实成绩明细。需要截图时，请先遮挡姓名、学号和其他个人信息。
